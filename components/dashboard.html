Alight Motion Premium

Baca panduan di bawah ini, lalu klik tombol Mulai Aktivasi untuk masuk ke sistem.

1 Apa Itu Dashboard Ini?

Dashboard ini buat ngatur aktivasi Alight Motion Premium. Jadi user gak perlu ribet cari-cari key manual, semua lewat sini. Admin bisa liat siapa aja yang udah aktivasi, masa aktifnya sampe kapan, dan bisa perpanjang / matiin kalo ada yang nakal.

2 Cara Aktivasi Buat User

  • Buka dashboard Ayaka-Sync, login pake akun lu
  • Di halaman utama, pencet tombol Aktivasi Premium
  • Masukin kode lisensi / kode aktivasi yang udah lu beli
  • Pencet Aktivasi Sekarang
  • Tunggu sampe muncul notif "Premium Aktif"
  • Buka Alight Motion lu, tutup total dulu aplikasinya, terus buka lagi
  • Cek di Alight Motion > Pengaturan > harusnya udah kebuka semua fitur premiumnya

3 Cara Cek Status Premium Lu

  • Masuk dashboard > Menu Status Saya
  • Di situ keliatan: Status: Aktif / Tidak Aktif / Expired, Tanggal aktivasi, Tanggal berakhir, Sisa hari premium lu
  • Kalo udah expired, fitur premium di Alight Motion bakal kekunci lagi otomatis

4 Fitur Yang Kebuka Kalo Udah Premium

  • Tanpa watermark saat export video
  • Export kualitas Full HD / 4K
  • Bisa pake semua efek premium, font premium, dan preset premium
  • Bisa pake keyframe, easing, dan vector graphic full
  • Bisa export tanpa iklan
  • Bisa simpan project tanpa batas

5 Cara Perpanjang Premium

  • Kalo masa aktif lu udah mau habis (tinggal 3 hari), bakal ada notif di dashboard
  • Pencet Perpanjang
  • Masukin kode baru yang lu beli
  • Premium lu langsung nambah masa aktifnya, gak perlu aktivasi dari nol lagi

6 Cara Pindah HP / Ganti Device

  • Premium itu nyangkut di 1 akun, bukan di 1 HP
  • Kalo ganti HP, tinggal login lagi di dashboard pake akun yang sama
  • Terus pencet Sinkronkan Device
  • Buka Alight Motion di HP baru, login, premium bakal ikut pindah
  • Maksimal 1 device aktif dalam 1 waktu. Kalo mau pindah, logout dulu device lama lu

7 Kalo Aktivasi Gagal, Lakuin Ini

  • Kode tidak valid: Cek lagi kode lu, jangan sampe ada spasi / huruf ketuker (O sama 0, I sama 1)
  • Kode sudah dipakai: Berarti kode itu udah dipake akun lain, hubungi admin
  • Sudah aktif tapi di AM masih free: Tutup total Alight Motion, hapus dari recent app, buka lagi, terus pencet Sync di dashboard
  • Server lagi error: Tunggu 5 menit, jangan spam pencet aktivasi berkali-kali

8 Aturan Buat User Premium

  • 1 kode cuma buat 1 akun, gak bisa dishare
  • Dilarang jual ulang kode / share akun ke orang lain
  • Kalo ketahuan share akun, admin berhak matiin premium lu tanpa refund
  • Jangan pake VPN pas aktivasi, nanti device ke-detect beda terus gagal

9 Buat Admin

  • Menu Kelola User buat liat semua user yang aktif
  • Bisa matiin premium user yang nakal pake tombol Nonaktifkan
  • Bisa nambahin kode baru di menu Tambah Kode
  • Bisa liat log aktivasi siapa aja yang baru aktivasi hari ini
